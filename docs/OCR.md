# OCR 文字擷取

[繁體中文](OCR.md) | [English](OCR.en.md)

提供文字選取的 OCR 備援與手動區域 OCR；辨識結果只複製到剪貼簿，不變更 PDF。

## 操作

- 工具列提供「複製文字」與「區域 OCR」兩種文字擷取模式。
- 一般預覽與全螢幕皆可使用。
- 兩者與「擷取圖片」模式互斥。

### 複製文字

1. 點工具列的「複製文字」按鈕。
2. 在頁面上拖曳選取文字；實際選到的文字會顯示高亮。
3. 放開滑鼠，將文字複製到剪貼簿。
4. 若原始文字疑似損壞，程式會自動嘗試 OCR；完成後查看狀態列並校對結果。

### 區域 OCR

1. 點工具列的「區域 OCR」按鈕，游標會切換為十字。
2. 在頁面或圖片上拖曳矩形，框選要辨識的範圍。
3. 放開滑鼠，辨識結果會複製到剪貼簿。
4. 若框選範圍為空白，保留原剪貼簿內容。

### 自動備援的觸發條件

- 正常文字直接複製，拖曳時只更新高亮。
- 放開滑鼠取得的文字含 U+FFFD（�）、Unicode 非字元、孤立代理碼，才啟動 OCR。
- 文字含控制字元時也會觸發，但正常換行與 <kbd>Tab</kbd> 不在此限。
- 在「複製文字」模式中，空白或純圖片選取不觸發 OCR。
- 若損壞映射剛好產生合法中文字，或原文使用私用區字元，仍沿用原始文字；無法偵測所有錯字。

## 辨識方式與限制

- 區域 OCR 支援掃描圖片、截圖及一般 PDF；拖曳期間不進行背景 OCR。
- 區域 OCR 會先偵測文字行，再將同一行的短橫線、底線等標記合併辨識。
- OCR 在現有背景程序中執行，將所選字形按行以 400 DPI 渲染；成功後複製辨識結果，狀態列提示校對。
- 大片區域會適度降低解析度，避免超過約 1,900 萬像素。
- 採用 RapidOCR 3.10.0 與 CPU 版 ONNX Runtime，直接在 Python 中辨識。
- 不呼叫 Tesseract 或其他外部執行檔，也不寫入暫存辨識影像。
- 第一次需要 OCR 時才載入模型，後續重用同一個引擎。
- 一般文字備援僅載入辨識模型；區域 OCR 首次使用時另載入偵測模型，兩者共用辨識引擎。
- 不載入方向分類模型；目前適合水平文字，旋轉或直排文字尚未完成辨識品質驗證。
- 模型或函式庫遺失、初始化失敗、結果為空／損壞，或平均字元信心低於 0.8 時，保留原始文字並顯示原因。
- 每次最多 30 行，每行影像上限 2,000 萬像素。
- 各行間檢查 60 秒總預算；原生推論進行中無法硬性中斷。
- OCR 可能有錯字、標點及排版差異，辨識後仍需校對。

## 辨識語言

OCR 使用同一套多語言辨識模型，支援以下語言：

- 支援繁體中文、簡體中文、英文與日文。
- 支援法文、德文、西班牙文、葡萄牙文、義大利文、越南文等多種拉丁字母語言。
- 不支援韓文。

- 上述語言共用同一個模型，不需要手動切換或另外下載語言包。
- 介面的中英文設定不會限制 OCR 辨識語言。
- 語言清單可參考 [RapidOCR 官方模型說明](https://rapidai.github.io/RapidOCRDocs/main/model_list/)，並以本專案固定使用的 RapidOCR 3.10.0 與 `PP-OCRv6_rec_small` 為準。
- 本專案的辨識品質測試主要集中在中英文，其他語言尚未完成實測。
- 模型支援某種語言不代表每份文件都能準確辨識，使用後仍需校對。

## 安裝與離線使用

安裝方式見 [安裝與啟動](../README.md#安裝與啟動)。

- OCR 執行環境與模型隨套件提供，不需要額外安裝工具或下載語言包。
- `rapidocr==3.10.0` 的 Python wheel 內附多語言辨識模型 `PP-OCRv6_rec_small.onnx`，約 20.3 MiB。
- 區域 OCR 另使用內附的偵測模型 `PP-OCRv6_det_small.onnx`，約 9.5 MiB。
- 使用明確本機模型路徑並檢查 SHA256，不使用預設模型自動下載流程。
- 執行時不連線傳送 PDF。
- 辨識模型 SHA256：`6f327246b50388f3c176ae304bd95767ea6dc0c9ae92153ef8cbe210b3c14884`。
- 偵測模型 SHA256：`090f04abcd9d9a7498bc4ebf677e4cb9bdce1fe4197ddb7e529f1ef44e1ff94f`。

- 桌面套件的模型收集、雲端建置與封裝自我檢查見 [技術文件：打包與發布](IMPLEMENTATION.md#15-打包與發布)。

## 驗證

```sh
uv run python -m pytest
```

- 觸發條件：正常文字、拖曳高亮與空白選取不觸發；損壞字元觸發；失敗保留原文。
- 辨識功能：本機模型離線推論、純圖片區域辨識與反向框選。
- 介面整合：模式切換、全螢幕、背景訊息協定與背景程序到剪貼簿的完整流程。
- 合成測試 PDF 在執行時產生，不將使用者的 PDF 加入儲存庫。
